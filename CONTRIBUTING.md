# Contributing

Thanks for your interest in contributing to this fork of `laravel-cloudflared`!

Guidelines

- Open an issue first to discuss larger changes or new features.
- Use feature branches and open Pull Requests against `main`.
- Keep commits focused and add tests for new behavior when possible.
- Follow PSR-12 coding style.

Testing

- Run unit tests with:

```bash
composer install --dev
composer test
```

- Use the `tests` directory for PHPUnit tests and `orchestra/testbench` for Laravel integration tests.

Reporting bugs

- Please include steps to reproduce, PHP version, OS, and relevant logs or error messages.
